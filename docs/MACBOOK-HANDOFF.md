# Перенос проекта на MacBook

Эта инструкция нужна, чтобы открыть тот же проект на MacBook, сохранить текущий дизайн и продолжить работу с Codex без потери контекста.

## Что уже хранится в GitHub

В репозитории находятся:

- весь исходный код сайта;
- изображения Hero, инструкторов и автомобилей;
- тесты и настройки проекта;
- README.md с быстрым запуском;
- AGENTS.md с полной памятью о проекте и принятых решениях;
- эта инструкция;
- инструкция по Telegram.

В GitHub намеренно нет .env.local, Telegram-токена и других секретов.

## 1. Подготовить MacBook

Откройте Terminal и установите системные инструменты Apple:

    xcode-select --install

Установите Node.js 22 LTS с официального сайта https://nodejs.org/ или через привычный менеджер версий. Затем проверьте:

    git --version
    node --version
    npm --version

Для Node должна отображаться версия 22.x или совместимая более новая LTS.

## 2. Скачать проект

В Terminal выполните:

    cd ~/Documents
    git clone https://github.com/fastnightshadow-bit/perekrestok-yaroslavl.git
    cd perekrestok-yaroslavl
    corepack enable
    pnpm install

Если macOS запросит доступ к папке Documents, разрешите его.

## 3. Восстановить локальные настройки

Создайте локальный файл:

    cp .env.example .env.local

Откройте .env.local и заполните:

    TELEGRAM_BOT_TOKEN=
    TELEGRAM_CHAT_ID=
    NEXT_PUBLIC_YANDEX_METRIKA_ID=110924306
    NEXT_PUBLIC_SITE_URL=https://perekrestok-yaroslavl.netlify.app

Настоящий Telegram-токен перенесите через менеджер паролей или заново получите у @BotFather. Не отправляйте его в Codex и не сохраняйте в GitHub.

Production-переменные уже должны храниться в Netlify. Локальный .env.local нужен только для проверки заявок на MacBook.

## 4. Запустить сайт

    pnpm dev

Откройте http://localhost:3000. Если порт занят, Next.js покажет другой адрес в Terminal.

Проверьте мобильную версию через адаптивный режим браузера и отдельно реальный опубликованный сайт:

https://perekrestok-yaroslavl.netlify.app

## 5. Проверить проект

Перед первой правкой выполните:

    pnpm test --run
    pnpm lint
    pnpm typecheck

Сборку запускайте отдельно, когда dev-сервер остановлен:

    pnpm build

Не запускайте pnpm build одновременно с pnpm dev или pnpm start: они используют одну папку .next.

## 6. Продолжить работу в Codex

1. Откройте в Codex папку perekrestok-yaroslavl.
2. В первой задаче напишите: «Прочитай AGENTS.md, README.md и docs/MACBOOK-HANDOFF.md. Продолжай текущий проект, не меняя утверждённый desktop Hero».
3. Codex должен сначала проверить git status и существующий код, а не собирать сайт заново.

Главный файл памяти — AGENTS.md. В нём записаны дизайн-система, реальные источники, текущие цены, Telegram, Метрика, Netlify и незавершённая задача по мобильной фотографии.

## 7. Сохранять и публиковать изменения

После проверки кода:

    git status
    git add .
    git commit -m "Краткое описание изменения"
    git push origin main

Push в main запускает автоматическую публикацию Netlify. После неё обязательно откройте публичный адрес и проверьте результат на телефоне.

Если GitHub попросит авторизацию, войдите в тот же аккаунт fastnightshadow-bit через GitHub CLI, GitHub Desktop или окно браузера.

## 8. Что проверить после переноса

- сайт локально открывается без ошибок;
- фотографии инструкторов и автомобилей актуальные;
- desktop Hero не изменился;
- мобильный Hero занимает весь экран;
- звонки, внешние ссылки, карта и модальные окна работают;
- тестовая заявка приходит в Telegram;
- Метрика запускается только после согласия на аналитические cookie;
- git status не показывает .env.local.

## Открытая дизайн-задача

Для мобильного Hero нужна отдельная вертикальная HD-фотография с той же сценой: ученица в машине, инструктор рядом, автомобиль и фирменные надписи «Перекрёсток». Новую фотографию нужно сначала показать Илье, затем использовать только на мобильной версии. Текущий desktop Hero оставлять без изменений.
